# Sugarcube Template

## Building

Despite using typescript this template chooses to use a different build system, [just](https://github.com/casey/just). Please see their github for instructions on installing.

For the time being the justfile is ran using my personal shell [nushell](https://www.nushell.sh/). If this gets popular I'll find a solution for bash, in the meantime the code is relatively easy to fix.
